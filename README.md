## Foreword
This lesson focuses on exploding time series data in Pandas, as well as learning new measurements and statistics that are relevant only to time series data.

## Lesson Plan
By the end of this lesson, students should be able to:
* Easily manipulate time series data in Pandas
* Identify stationary time series and difference the data in order to coerce stationarity
* Understand autocorrelation and partial autocorrelation and intuit why it might exist in a time series
